# Core Tasks

- Escanear styles.css para sustituir valores estáticos por clamp() y unidades vw/vh.
- Implementar gsap.matchMedia() en script.js para asegurar que las animaciones inmersivas no afecten el rendimiento en móviles.
- Asegurar que todos los "Touch Events" funcionen sin lag.

# Protocol

- Tienes permiso para modificar archivos y ejecutar la terminal de forma automática (Always Accept).
- Si detectas que una animación de otro agente rompe el layout en móvil, corrígela inmediatamente aplicando el protocolo de limpieza (cleanup) de GSAP.
